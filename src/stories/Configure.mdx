# @codeincrypt/design-system

A React component library built as thin wrappers around [Ant Design](https://ant.design/) v5. Every component forwards all of its props to the underlying Ant Design component, so the full Ant Design API is available.

## Installation

```bash
npm install @codeincrypt/design-system antd react react-dom
# or
yarn add @codeincrypt/design-system antd react react-dom
# or
pnpm add @codeincrypt/design-system antd react react-dom
```

Requirements: `react` and `react-dom` ^18, and `antd` ^5. Ant Design v5 uses CSS-in-JS, so no stylesheet import is needed.

## Update the package

```bash
# update to the latest version within your semver range
npm update @codeincrypt/design-system

# or install the newest release explicitly
npm install @codeincrypt/design-system@latest
```

```bash
yarn upgrade @codeincrypt/design-system --latest
pnpm update @codeincrypt/design-system --latest
```

Check the installed version with `npm ls @codeincrypt/design-system`.

## Usage

All components are named exports:

```jsx
import { Button } from '@codeincrypt/design-system';
```

### Next.js (App Router)

Import from a file marked `'use client'`.

```jsx
'use client';
import { Button } from '@codeincrypt/design-system';

export default function ClientButton() {
  return <Button type="primary">Click</Button>;
}
```

## Theming

Wrap your app in `ThemeProvider`. Use `useThemeMode` to read or toggle the mode, and pass `tokens` to override design tokens. Exported tokens: `tokens`, `colors`, `spacing`, `typography`, `radius`, `antTokens`.

```jsx
import { ThemeProvider, useThemeMode, Button } from '@codeincrypt/design-system';

function ThemeToggle() {
  const { mode, toggleMode } = useThemeMode();
  return <Button onClick={toggleMode}>Switch to {mode === 'dark' ? 'light' : 'dark'}</Button>;
}

export default function App() {
  return (
    <ThemeProvider defaultMode="light" tokens={{ colorPrimary: '#6366f1' }}>
      <ThemeToggle />
    </ThemeProvider>
  );
}
```

## Composite components

### Dashboard

A ready-made page with stat cards and a table. Every prop is optional and falls back to demo data.

```jsx
<Dashboard title="Dashboard" subtitle="Overview of your business" />
```

### DashboardLayout

Sidebar and header shell with a built-in dark-mode switch (requires `ThemeProvider`).

```jsx
<ThemeProvider>
  <DashboardLayout
    logo="My App"
    menuItems={[{ key: 'home', label: 'Home' }, { key: 'users', label: 'Users' }]}
    selectedKey="home"
    onMenuSelect={(key) => console.log(key)}
    user={{ name: 'Karthik' }}
  >
    Page content
  </DashboardLayout>
</ThemeProvider>
```

### DataTable
